# Grading: 05-mobile-checkout

PASS requires all:
1. Conventional flow preserved (user pinned it); no novel checkout inventions.
2. Full form contract: visible labels, autocomplete/inputmode/type correct, paste allowed, inline errors + focus to first error, in-flight protection.
3. Touch targets >= 44px, inputs >= 16px font, safe-area insets.
4. Redundant entry avoided (same-as-billing mechanism).
5. No invented trust signals; payment path free of decorative motion.

FAIL indicators: placeholder-as-label; blocked paste; disabled-until-valid submit; fabricated reviews/badges; novelty steps.

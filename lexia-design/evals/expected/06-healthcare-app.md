# Grading: 06-healthcare-app

PASS requires all:
1. Audience-driven accessibility beyond floors: enlarged targets/text, plain language, high contrast, generous spacing.
2. Calm precise register; zero cutesy copy on medical surfaces.
3. Booking flow: error prevention, confirmation, undo/cancel path, no time pressure.
4. Consistent help placement; redundant entry avoided; few choices per screen.
5. No fabricated clinics, doctors, or medical claims; medication states never color-only.

FAIL indicators: dark patterns; emoji icons; dense expert layouts for elderly users; comprehension gated on animation.

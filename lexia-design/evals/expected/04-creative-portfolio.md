# Grading: 04-creative-portfolio

PASS requires all:
1. Variance 7-9 with a committed direction contract (thesis, breaks-if, signature move) — experimentation is structured, not collaged.
2. Distinctiveness honestly assessed via the interchangeability test; the render is describable from memory.
3. Imagery leads; chrome recedes; case studies reachable within two interactions.
4. Keyboard + reduced-motion complete despite experimental layer.
5. If motion is heavy, it is one authored system, interruptible, with cleanup.

FAIL indicators: template with a weird font; effect collage from award sites; novelty that hides navigation; motion without reduced-motion.

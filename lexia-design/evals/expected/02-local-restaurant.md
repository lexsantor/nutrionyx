# Grading: 02-local-restaurant

PASS requires all:
1. Direction argued from the actual place (Gracia, Catalan cuisine, family history), not "restaurant template with serif".
2. If a warm/cream palette is chosen, an alternative was explored first (model-priors checkpoint visible in the brief).
3. No invented prices, reviews, awards, or hours; labeled slots where data is missing.
4. Real photography is the structural material; no stock substitutes.
5. Semantic HTML, works without JS, keyboard navigable.

FAIL indicators: generic template; cream+Fraunces reflex with no exploration; fabricated menu/reviews; broken no-JS experience.

# Grading: 12-existing-design-system

PASS requires all:
1. Tokens and component inventory read before design; evidenced in the report.
2. Page built from their components; zero off-token values (detector clean on system/off-token-colors).
3. System gaps extended via their conventions and flagged as proposals, not silently added.
4. No external component library, no parallel styles, no new palette.
5. Coherence scored against their system.

FAIL indicators: plugin directions imposed; new tokens uninvited; shadcn/etc. imported; off-token hexes.

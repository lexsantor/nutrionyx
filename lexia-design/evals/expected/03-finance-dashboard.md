# Grading: 03-finance-dashboard

PASS requires all:
1. Product register: variance <= 6, density appropriate, convention followed.
2. Tabular numerals on all monetary values; semantic colors reserved; state never color-only.
3. Loading/empty/error per data region; skeletons mirror final layout.
4. Motion near zero on daily-use paths (frequency gate cited or applied).
5. Demo data labeled as example; neutral register in copy.
6. Chart accessibility: labeled series, contrast-safe palette.

FAIL indicators: decorative animations; playful copy on money; invented balances presented as real; card-in-card everywhere.
